# ANYON Landing Page

AI-Powered Development Platform

## 개발

```bash
# 의존성 설치
npm run install:all

# 개발 서버 시작
npm run dev

# 빌드
npm run build

# 프리뷰
npm run preview
```

## 프로젝트 구조

```
anyon-claude/
├── landing/              # 랜딩 페이지 소스
└── archived-assets/      # 보관된 이미지/비디오 자산
```

## 자산 관리

모든 이미지, 비디오 파일은 `archived-assets/` 폴더에 보관되어 있습니다.
